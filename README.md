
# Skill Swap

## Project Description

Skill Swap is a web application designed for college students
and recent graduates who want to share and learn new skills.

Students will be able to create profiles, display their skills,
and connect with other students.

The goal is to make learning more affordable, accessible,
and convenient.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js (planned for backend development)
- Express.js (planned)
- Sequelize (planned for database management)

## Current Development

This project is currently in Sprint 1.
We are working on the basic frontend structure
and preparing the application for future features.
